# RupEasy Frontend

Rupeezy is a frontend prototype for an AI-powered microloan platform designed to help borrowers and lenders connect through a simple and modern interface.

## Features

- User authentication pages
- Loan application interface
- Credit score checking UI
- Borrower dashboard
- Lender dashboard
- Responsive design
- Clean UI using HTML, CSS, and JavaScript

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Folder Structure

```bash
frontend/
│
├── templates/
├── static/
│   ├── css/
│   ├── js/
│   └── images/
```

## How to Run

1. Clone the repository

```bash
git clone <repo-link>
```

2. Open the project folder

3. Run using VS Code Live Server  
OR  
Open `index.html` directly in browser.
